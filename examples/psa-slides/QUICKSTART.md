# Quick Start Guide

Get your PSA presentation running in 3 easy steps!

## Step 1: Install Dependencies
```bash
cd examples/psa-slides
npm install
```

## Step 2: Start the Development Server
```bash
npm run dev
```

## Step 3: Open in Your Browser
Navigate to: **http://localhost:3000**

That's it! 🎉

---

## Using the Presentation

### Navigation
- **Keyboard**: Press ← → arrow keys to navigate
- **Mouse**: Click "Previous" or "Next" buttons

### Full Screen Mode
- Press **F11** on Windows/Linux
- Press **Cmd+Ctrl+F** on Mac

### Slide Overview
You have **8 slides** in total:
1. Title Slide (Talha Muhammad)
2. Objective
3. Target Audience
4. Creative Approach (feat. Yousaf)
5. Key Content
6. Call to Action
7. Reflection (What I Learned)
8. Credits

## For Production

### Build for Production
```bash
npm run build
npm start
```

### Deploy to Vercel (Easiest!)
1. Push to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repository
4. Click "Deploy"
5. Done! ✨
