# One Small Choice - PSA Presentation

A clean and highly sophisticated PSA (Public Service Announcement) slide presentation built with Next.js, focusing on integrity and anti-corruption awareness.

## Overview

This presentation addresses the topic of integrity and anti-corruption through the story "One Small Choice," which demonstrates how small corrupt offers can pressure young people and why choosing integrity protects their future.

**Presenter:** Talha Muhammad  
**Course:** MPU 2323 PSA

## Features

- 🎨 **Clean, Modern Design** - Professional gradient background with sophisticated white slide cards
- 🖼️ **Custom SVG Icons** - Clean, professional icons for each slide (no emojis)
- ⌨️ **Keyboard Navigation** - Use arrow keys to move between slides
- 🖱️ **Click Navigation** - Next/Previous buttons for easy navigation
- 📱 **Responsive Design** - Works on various screen sizes
- 🎯 **8 Comprehensive Slides** covering all aspects of the PSA project

## Slides Included

1. **Title Slide** - Introduction with presenter name
2. **Objective** - Purpose and goals of the PSA
3. **Target Audience** - Who this message is for
4. **Creative Approach** - How the story is told (featuring Yousaf character)
5. **Key Content** - Main story elements and message
6. **Call to Action** - What viewers should do
7. **Reflection** - What was learned from creating the PSA
8. **Credits** - Acknowledgments and attributions

## Getting Started

First, install the dependencies:

```bash
npm install
# or
pnpm install
# or
yarn install
```

Then, run the development server:

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the presentation.

## Navigation

- **Arrow Keys**: Use Left/Right arrow keys to navigate between slides
- **Buttons**: Click "Previous" or "Next" buttons at the bottom of each slide
- **Slide Counter**: Current slide number and total slides are displayed in the center

## Technology Stack

- **Next.js** - React framework with App Router
- **TypeScript** - Type-safe development
- **React** - UI components
- **Custom SVG Icons** - Professional, scalable vector graphics

## Customization

To customize the slides, edit `/app/page.tsx`:

- Modify the `slides` array to change content
- Update the `styles` object to change colors and layout
- Add or remove slides as needed

## Building for Production

```bash
npm run build
npm start
```

This will create an optimized production build and start the production server.

## Key Message

**Integrity > Shortcuts**

This PSA emphasizes that:
- Corruption often starts with "small favours"
- Real pressure usually comes via messages, not face-to-face
- Integrity requires courage and a clear mindset
- Protecting your reputation and future is worth the effort
