# Visual Design Guide

## Overall Design System

### Color Palette
- **Primary Purple**: `#667eea`
- **Secondary Purple**: `#764ba2`
- **Dark Text**: `#2d3748`
- **Medium Text**: `#4a5568`
- **Light Text**: `#718096`
- **Disabled**: `#cbd5e0`
- **White**: `#ffffff`

### Typography
- **Title**: 48px, Bold (700)
- **Subtitle**: 32px, Medium (500)
- **Presenter**: 24px, Italic
- **Content**: 22px, Regular
- **Bullet**: 28px, Bold
- **Navigation**: 18px, Semi-bold (600)
- **Font Family**: System UI, -apple-system, sans-serif

### Layout
- **Container**: Full viewport height with gradient background
- **Slide Card**: 
  - Max width: 900px
  - Padding: 60px 80px
  - Min height: 600px
  - Border radius: 20px
  - Shadow: 0 20px 60px rgba(0, 0, 0, 0.3)

### Icons
- **Size**: 80x80 pixels
- **Style**: Outline (stroke-based SVG)
- **Stroke width**: 2px
- **Color**: Primary purple (#667eea)

## Interactive Elements

### Navigation Buttons
- **Enabled State**: 
  - Background: #667eea (purple)
  - Text: white
  - Hover: Slight brightness increase
  - Border radius: 10px
  - Padding: 12px 30px

- **Disabled State**:
  - Background: #cbd5e0 (gray)
  - Opacity: 0.5
  - Cursor: not-allowed

### Slide Counter
- Format: "X / 8"
- Color: #718096 (gray)
- Font weight: Semi-bold
- Centered between buttons

### Hint Text
- "Use arrow keys or click buttons to navigate"
- Color: White with 80% opacity
- Position: Below slide card
- Font size: 16px

## Responsive Considerations

The design is optimized for:
- Desktop: 1920x1080 and above
- Laptop: 1366x768
- Tablet: 768x1024 (landscape mode recommended)
- Mobile: Readable but presentation mode preferred on larger screens

## Animation & Transitions

While not currently implemented, suggested transitions:
- Slide changes: Fade or horizontal slide
- Button hover: Scale 1.05 with 0.3s ease
- Icon entrance: Fade-in from top

## Accessibility

- High contrast between text and background
- Large, readable fonts
- Clear navigation indicators
- Keyboard accessible
- Semantic HTML structure
