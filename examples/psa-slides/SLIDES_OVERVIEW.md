## Design Features

### Visual Design
- **Background:** Sophisticated purple gradient (from #667eea to #764ba2)
- **Slide Cards:** Clean white cards with rounded corners and shadow effects
- **Icons:** Professional, scalable SVG icons (no emojis) in the brand color (#667eea)
- **Typography:** Modern system fonts with clear hierarchy
- **Bullet Points:** Custom styled with purple bullets

### Interactive Features
- **Keyboard Navigation:** Left/Right arrow keys to navigate
- **Click Navigation:** Previous and Next buttons
- **Slide Counter:** Shows current slide / total slides
- **Responsive Design:** Works on various screen sizes

### Technical Stack
- **Framework:** Next.js 15+ (App Router)
- **Language:** TypeScript
- **UI Library:** React 18+
- **Styling:** CSS-in-JS (inline styles)
- **Icons:** Custom SVG components

## Key Message
**Integrity > Shortcuts**

This presentation emphasizes the importance of maintaining integrity in the face of corruption, particularly focusing on how young people face pressure through modern communication channels like text messages. The story demonstrates that choosing the honest path, though harder, protects one's future and reputation.
